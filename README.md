# Membuat algoritma memindahkan air di dalam gelas

1. Mulai
1. Siapkan gelas kosong, gelas berisi teh dan gelas berisi kopi
1. Pindahkan teh atau kopi ke gelas kosong
1. Jika teh pindah ke gelas kosong maka masukan kopi ke gelas bekas teh; Jika kopi pindah ke gelas kosong maka masukan teh ke gelas bekas kopi;
1. Pindahkan 
1. Selesai
